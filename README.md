# MilicaTadicOOP2

Java AWT aplikacija za unos aerodroma i letova, prikaz mape i simulaciju letova.

## Pokretanje u Eclipse-u

1. Izaberite **File > Import > Existing Projects into Workspace**.
2. Izaberite direktorijum ovog projekta.
3. Pokrenite klasu `userinterface.MainForm` kao Java Application.

Projekat je podešen za Java 8 ili noviju verziju.

## Ulazni podaci

U korenu projekta nalaze se primeri tekstualnih datoteka koje se mogu učitati iz aplikacije.
